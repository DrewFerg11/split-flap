---
title: Firmware
description: Software for display modules and the controller.
---

Module firmware drives each drum; a controller coordinates the display.
Firmware sources and build instructions live in the
[firmware directory](https://github.com/DrewFerg11/split-flap/tree/main/firmware).

## Downloads

Published binaries, when available, are attached to
[GitHub releases](https://github.com/DrewFerg11/split-flap/releases).

## Flash firmware

A browser-based flasher is planned. This page will link to it when supported
controller firmware and flashing instructions are available.

For now, use the build and upload instructions for your firmware target in
the source repository.
