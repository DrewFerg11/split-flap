Browser demos will let you try layouts, inspect the flaps they need, and watch
modules move forward through their drum order.

## Premier League (EPL)

The first planned demo covers standings, matchday layouts, and other display
modes. It will use sample data so you can explore without connecting a display
or setting up a football API.

:::note[Coming next]
The interactive Premier League demo will be added in a separate change.
:::

Each application will share a reusable display engine, with its own drum
contents, layout, and views.
