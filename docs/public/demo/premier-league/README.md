# Premier League demo

Views and invented samples are ported from Drew's confirmed local mockup,
board-mockup.html (last modified 2026-10-24).
Source SHA-256: e451520dbd4346f65a1feafb828e8aa7123f3771cc8f8368fa44b93b50a6368c.

data.js holds samples; views.js holds views; config.js holds the physical
layout; app.js mounts the shared engine. Drum lists come from
`applications/premier-league/flap-sets/flap-sets.json`, generated by the
application's `build_json.py` from its authoritative `flap-sets.md` table.
Edit that table and regenerate the JSON when changing printed flaps.
Before dev, check, build, and demo tests, npm runs `scripts/prepare-flaps.mjs`
to write an ignored `flap-sets.generated.js` beside config.js. Astro copies
this local ES module unchanged; no runtime fetch or bundler is needed.
`flaps.js` maps JSON entries to renderer tokens without changing their indices.

The main-name, main-digit, and header-name dividers are at slot 46, directly
before the six colours. Header digits retain the notes' three repeated
13-item blocks and seven spares; no divider is printed on that drum.
All four lists have 52 entries. UI counts come from list lengths.
Table slot 46 is firmware flap 45 (zero-based).

The Astro route discovers this folder from manifest.json. A second app needs
only a new sibling folder with manifest, config, views/data, and app.js. It
can use a different row count, columns, physical sizes, and drum lengths.

When updating the mockup, change the app files rather than adding league
logic to ../engine/. All original views are covered by app validation tests.
Stale captions claiming GOALS FOR/AGAINST were missing header flaps have been
corrected. Text-only LION and LIVER placeholders are preserved. No club
crests or league logos are distributed.

The three `wildcard` symbols at main-digit firmware flaps 42–44 are
undecided in the shared data. The explicit `wildcards.digit` list in config.js
layers LIVER, jersey, and boot illustrations onto those positions for the
demo only; it does not specify printed artwork. The shared `pl-lion` symbol
maps to the demo's `#lion` text placeholder. Unknown kinds, unsupported
colours/symbols, missing wildcard illustrations, and incorrect lengths fail
validation rather than silently inventing printable flaps.
