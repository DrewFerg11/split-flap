# Premier League (EPL)

The first application: a Premier League display on split-flap modules, showing the league
table (one team per row, points on two digit modules) and live scores (three rows per game).
Rows aren't fixed at 20: the display is built to grow past it.

**Not migrated yet.** The build instructions, wiring, rail, flap sets and controller logic are still
in the development workspace (`split-flap-display-pcb/builds/league-table/`). Releases will be
tagged `app/premier-league/vX.Y.Z`.
